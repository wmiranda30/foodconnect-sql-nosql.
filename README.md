
# 🍔 FoodConnect — Banco de Dados SQL e NoSQL

### 📚 Estudo de Caso Acadêmico | Análise e Desenvolvimento de Sistemas

## 🎯 Sobre o projeto

Este projeto foi desenvolvido a partir de um desafio acadêmico da UNIASSELVI, com o objetivo de analisar soluções de banco de dados para uma plataforma fictícia de delivery chamada **FoodConnect**.

A atividade permitiu compreender como bancos de dados SQL e NoSQL podem trabalhar juntos para melhorar a organização, o desempenho e a segurança das informações.

## 🔎 O problema

A FoodConnect conecta clientes, restaurantes e entregadores.

Durante a análise, foram identificados três desafios principais:

- Lentidão nas consultas durante horários de maior movimento.
- Necessidade de armazenar diferentes tipos de informações.
- Dificuldades relacionadas ao crescimento da plataforma e ao acompanhamento das entregas em tempo real.

## 🛠️ Tecnologias analisadas

| Tecnologia | Aplicação proposta |
|---|---|
| 🐘 PostgreSQL | Armazenamento de clientes, pedidos e pagamentos |
| 🍃 MongoDB | Preferências dos usuários e histórico de navegação |
| ⚡ Redis | Cache e acesso rápido a informações temporárias das entregas |
| 🔐 SQL e transações ACID | Organização e integridade dos dados |

## 💡 Proposta de solução

A análise propõe combinar diferentes tecnologias de armazenamento conforme as necessidades da plataforma.

### 1. Banco de dados relacional

Utilizar PostgreSQL para organizar informações estruturadas, como cadastros, pedidos e pagamentos.

### 2. Banco de dados NoSQL

Utilizar MongoDB para informações mais flexíveis, como preferências e histórico de navegação.

### 3. Desempenho e cache

Utilizar Redis para acelerar consultas frequentes e armazenar temporariamente informações das entregas.

### 4. Integração e segurança

Considerar mecanismos de integração, controle de acesso, criptografia, backups e proteção dos dados conforme a LGPD.

## 📖 Principais aprendizados

Durante o estudo de caso, pude compreender:

- As diferenças entre bancos SQL e NoSQL.
- A importância da modelagem de dados.
- O papel das transações ACID.
- Como índices e cache podem melhorar o desempenho.
- A importância da escalabilidade e da segurança.
- Como escolher tecnologias de acordo com as necessidades de negócio.
